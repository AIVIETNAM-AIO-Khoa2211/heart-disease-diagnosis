# Source Code

Reusable Python modules used by the notebooks and the demo app:

- `data_loader.py` — load raw / processed data
- `preprocessing.py` — data cleaning and feature engineering
- `model_training.py` — model definitions and training (Naive Bayes, KNN, Decision Tree, Random Forest, AdaBoost, Gradient Boosting, XGBoost)
- `evaluation.py` — evaluation metrics and result aggregation
- `explainability.py` — TreeSHAP-based explainability
- `visualization.py` — plotting utilities
